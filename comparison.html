Zero-Trust Ingestion & Migration Engine

🚀 OpenCrawling

The open-source reference engine for the Open Ingestion Standard (OIS), built on Java 25 and Spring Boot 4 to bridge enterprise repositories and real-time event streams with AI and vector infrastructure.

  • Hybrid Pull + gRPC Push: Combine scheduled repository crawlers with sub-millisecond HTTP/2 Protobuf v3 gRPC Push streaming (oc-grpc-push-connector).
  • End-to-End Zero-Trust ACLs: Preserves allow/deny SIDs and multi-tenant boundaries from Doxis, CMIS, Alfresco, JDBC, and gRPC directly into vector queries and the Secure MCP Server.
  • Crash-Resilient & Scalable: Isolates parsing in Apache Tika 4.1 PipesForkParser child JVMs, offloads binaries to Apache Ozone (ofs://), and scales embedding workers horizontally via Kafka.
  • Lakehouse Audit & OpenAPI 3.1: Generates ZSTD Parquet ledgers queryable via embedded DuckDB SQL, and exports OpenAPI 3.1 specs directly as LLM tool definitions via oc openapi tools.
Legacy Enterprise Crawler

🏛️ Apache ManifoldCF

The pioneering open-source enterprise crawler created for classic keyword search engines like Apache Solr and Elasticsearch.

  • Proven Authority Model: Introduced early repository ACL and Active Directory SID synchronization for keyword search indexes.
  • Legacy Architecture: Relies on monolithic PostgreSQL polling tables, classic thread pools, and XML configurations without Kafka decoupling or native vector chunking.
  • 1-Click Migration to OpenCrawling: Use OpenCrawling's oc-mcf-migrator (oc mcf audit / oc mcf convert) to modernize legacy ManifoldCF jobs into OIS pipelines automatically.
RAG & AI Frameworks

🦜 LangChain / LlamaIndex

Popular Python/TypeScript SDKs for building application-level LLM orchestration, prompt chains, and agent workflows.

  • Rich App Orchestration: Unmatched ecosystem for prompt engineering, agent memory, query routing, and LLM evaluation.
  • In-Memory Loader Limits: Built for application logic rather than distributed ingestion; lacks process-isolated Tika parsing, Claim-Check offloading, and Lakehouse audit ledgers.
  • Better Together: Let OpenCrawling handle enterprise ingestion, ACL synchronization, and vector indexing, then connect LangChain or LlamaIndex agents via OpenCrawling's Secure MCP Server.
Document Partitioning & OCR

🧩 Unstructured.io

Specialized file preprocessing libraries and commercial cloud APIs for partitioning complex layout PDFs, slides, and scanned images.

  • Layout & Vision Detection: Uses vision models and OCR to detect bounding boxes, tables, and headers in complex visual documents.
  • No Native Authority Service: Focuses on document element partitioning rather than multi-tenant ECM authority translation or bit-for-bit Apache Ozone migration.
  • Cloud vs. Self-Hosted: Advanced connectors and high-throughput pipelines are part of the commercial Unstructured Platform, whereas OpenCrawling is 100% Apache 2.0.
Web-Scale Scrapers

🕸️ Apache Nutch

A mature, battle-tested open-source web crawler built for massive public internet scraping on Hadoop clusters.

  • Massive Public Web Crawling: Excels at link-graph traversal and politeness throttling across millions of public web domains.
  • Batch MapReduce Heritage: Heavy Hadoop infrastructure compared to OpenCrawling's lightweight Java 25 Virtual Threads or StormCrawler streaming integration.
  • No Intranet ECM Security: Designed for public HTTP pages; lacks connectors for Doxis, CMIS, Alfresco, BPMN engines, or Zero-Trust ACL mapping.
ETL & Data Integration

🌊 Airbyte / Fivetran

Leading ELT platforms for replicating structured relational databases and SaaS API tables into analytical data warehouses.

  • 300+ SaaS Table Connectors: Ideal for syncing Salesforce, Stripe, or Postgres tables into Snowflake, BigQuery, or Databricks.
  • Not Built for Unstructured RAG: Replicates tabular rows as-is without Apache Tika binary extraction, Auto-Narrativization Copilot prose synthesis, or document ACL inheritance.
  • Complementary via SeaTunnel: OpenCrawling integrates natively with Apache SeaTunnel for distributed multi-sink fan-out while preserving OIS chunks and vectors.
Dataflow Routing

⚡ Apache NiFi

A visual drag-and-drop dataflow routing system designed to move and transform files and events across corporate networks.

  • Visual Flow Canvas: Powerful UI for backpressure management, data provenance, and protocol mediation.
  • DIY RAG & Security: Requires custom processors to implement semantic token splitting, decoupled embedding scale-out, OIS tombstone lifecycles, and vector store ACL enforcement.
  • gRPC Bridge Ready: NiFi flows can push real-time documents directly into OpenCrawling's oc-grpc-push-connector on port 9096 to gain instant RAG and ACL capabilities.
Commercial SaaS Search

🧠 Glean

A turnkey, closed-source SaaS enterprise search and AI assistant that federates knowledge across cloud workplace tools.

  • Polished End-User SaaS: Delivers a ready-to-use chat and search web app across Slack, Google Workspace, and Jira.
  • Closed Ecosystem & Lock-In: Proprietary commercial SaaS with per-seat licensing; cannot be self-hosted in air-gapped environments or customized with open SPIs.
  • No Open Data Liberation: Data stays inside Glean's index, whereas OpenCrawling lets you route into any open vector database or Apache Ozone Lakehouse.
Search & Vector Index Engine

🔍 Elastic / OpenSearch

Industry-standard distributed search and analytics engines offering lexical BM25 and dense vector kNN indexing.

  • World-Class Retrieval Index: Exceptional hybrid lexical + vector search performance at petabyte scale.
  • Index Engine, Not a Zero-Trust Middleware: Lacks native Doxis/BPMN/CMIS crawlers, Auto-Narrativization Copilot, and Lakehouse Parquet audit ledgers out of the box.
  • First-Class OpenCrawling Target: OpenCrawling sits upstream of OpenSearch, Solr 10, Vespa, and Luxir—feeding them clean, chunked, embedded, and ACL-stamped documents.
