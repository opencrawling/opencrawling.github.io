Pluggable Zero-Trust Context Retrieval

Secure Model Context Protocol (MCP) Server

Give AI models and autonomous agents direct access to enterprise knowledge databases while authoritatively enforcing Zero-Trust Access Control Lists (ACLs) with explicit deny precedence across 9 target vector & search engines.

View Full Wiki Documentation Explore Architecture

Pluggable 9 Vector & Search Engines

Unified McpVectorSearchBackend SPI supporting PostgreSQL (pgvector), Vespa, Qdrant, Milvus, OpenSearch 2.x/3.x, Apache Solr, Luxir, and Hyland OpenArch with query-time Ollama embedding generation.

Zero-Trust Guard (McpAclEvaluator)

Server-side defense-in-depth authorization with authoritative explicit deny precedence. Denials strictly override group grants across structured OIS permissions, flat arrays, and legacy ACLs.

Identity & Role Propagation

Resolves caller principal identities (email, username, SID) and active groups/roles at query time. Matches Active Directory, LDAP, BPMN assignee, and CMIS ACL tokens seamlessly.

Streamable HTTP & SSE Transports

Full support for Spring AI 2.0 Streamable HTTP (/mcp with Mcp-Session-Id session negotiation) and legacy Server-Sent Events (/mcp/sse) for high-performance agentic RPCs.

AIOps Observability MCP Tools

Built-in system telemetry tools (fetchJobTraces, getErrorLogs, queryThroughputMetrics) allow connected LLMs and the Admin Copilot to diagnose cluster health and Virtual Thread traces.

Multi-Dimension Vector Routing

Dynamically routes queries across dimension-specific index collections (384 for lightweight local models, 768 for nomic, and 1024 for mxbai-embed-large) with claim-check URI resolution.

Exposed MCP Tools Specification

The canonical knowledge retrieval, Hyland OpenArch repository, backward-compatible Vespa, and AIOps observability tools advertised via tools/list.

secureVectorSearch Canonical Knowledge Search

Performs semantic vector similarity search on indexed enterprise documents across any configured vector backend, pre-filtering candidates and authoritatively evaluating caller identity and ACL rules.

Parameter Type Required Description
query String Yes Natural language search phrase or keywords.
userPrincipal String Yes User email or principal identity performing the query (e.g. alice@company.com).
userRoles String Optional Comma-separated roles/groups (e.g. finance,engineering).
maxResults Integer Optional Maximum top-K candidate results to return (default: 5).
minScore Double Optional Minimum vector similarity threshold from 0.0 to 1.0 (default: 0.0).
dimensions Integer Optional Target vector dimension store (384, 768, or 1024).
getDocumentContent Document Retrieval

Retrieves complete document content and metadata for a specific URI, verifying caller authorization and resolving claim checks prior to payload retrieval.

Parameter Type Required Description
documentUri String Yes Target document URI (e.g. file:///data/reports/q3.pdf).
userPrincipal String Yes User principal identity verifying access rights.
userRoles String Optional Comma-separated group memberships of caller.
dimensions Integer Optional Target vector dimension selector (384, 768, 1024).
listAccessibleSources Source Discovery

Returns a list of all indexed documents and knowledge sources accessible to the specified user identity, enforcing caller authorization scoping.

Parameter Type Required Description
userPrincipal String Yes User principal identity for ACL enumeration.
userRoles String Optional Comma-separated group memberships.
dimensions Integer Optional Target vector dimension store.
openarch_search & openarch_fetch_document Hyland OpenArch Native

Dedicated tools for querying Hyland OpenArch directly: openarch_search(query, userPrincipal, userRoles, maxResults, minScore) executes semantic + HXQL search via /api/query/embedding, and openarch_fetch_document(documentId, userPrincipal, userRoles) retrieves full SysFile metadata & text after evaluating sys_acl permissions.

vespaSecureVectorSearch Vespa Backward-Compatible

Active when output.type=vespa. Executes hybrid BM25 + dense vector ranking directly against Vespa YQL, pushing explicit security_denied_read exclusions into the search query. Also preserves vespaGetDocumentContent and vespaListAccessibleSources.

ObservabilityMcpTools (AIOps) AIOps Telemetry Tools

System-level observability tools: fetchJobTraces(jobId, limit), getErrorLogs(jobId, severity), and queryThroughputMetrics(timeWindowMinutes) allow AI agents and Copilots to query live engine health without exposing underlying document data.

Decoupled Integration Test Suite (test-mcp-decoupled.sh)

OpenCrawling includes an automated end-to-end integration test validating the entire MCP server in a decoupled multi-container deployment (PostgreSQL, Kafka, Ollama, Redis, consumers, oc-mcp-server):

# Run standalone test script
./scripts/test-mcp-decoupled.sh

# Or run via master integration test runner with keyword filter
./run-integration-tests.sh mcp

16-Step Automated Verification Pipeline:

Step 1 - 3
Cluster Readiness
Boots decoupled Docker Compose cluster, checks Ollama model puller exit code 0, and validates MCP Streamable HTTP readiness (accepting 200/400/405).
Step 4 - 5
Handshake & Session
Negotiates JSON-RPC 2.0 initialize protocol, extracts Mcp-Session-Id header, issues notifications/initialized, and checks ping.
Step 6 - 7
Tool Introspection & AIOps
Validates advertised tools schema via tools/list and executes live AIOps observability tool calls (fetchJobTraces, getErrorLogs).
Step 8 - 9
Multi-ACL OIS Ingestion
Streams public, role-restricted, and explicit-deny documents through Kafka and Ollama into pgvector, asserting authoritative Zero-Trust filtering.
Step 10 - 12
Explicit Deny Precedence
Asserts that callers with group permissions who match an explicit deny rule are authoritatively rejected. Exercises multi-dimension queries (1024).
Step 13 - 16
Tombstone Delete & Parity
Verifies OIS document lifecycle tombstone DELETE purges vectors from MCP search results, verifies REST parity, and runs in-process backend SPI JUnit tests.

Query the MCP server asynchronously using the Python mcp library:

import asyncio
from mcp import ClientSession
from mcp.client.sse import sse_client

async def main():
    async with sse_client("http://localhost:8080/mcp/sse") as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()
            
            result = await session.call_tool(
                "secureVectorSearch",
                arguments={
                    "query": "Q3 Financial Growth Strategy",
                    "userPrincipal": "alice@company.com",
                    "userRoles": "finance,executives",
                    "maxResults": 5
                }
            )
            print(result.content)

asyncio.run(main())

Consumer settings & Service injection in Spring Boot Java microservices:

# application.yml:
spring:
  ai:
    mcp:
      client:
        enabled: true
        name: opencrawling-client
        sse:
          opencrawling-server:
            base-url: http://localhost:8080
            sse-endpoint: /mcp/sse

// Java Service Code:
@Autowired
private McpClient mcpClient;

public String searchKnowledge(String userEmail, String query) {
    var response = mcpClient.callTool("secureVectorSearch", Map.of(
        "query", query,
        "userPrincipal", userEmail,
        "userRoles", "engineering"
    ));
    return response.content().toString();
}

Direct Streamable HTTP JSON-RPC 2.0 handshake and tool execution via cURL:

# 1. Initialize MCP session and capture returned Mcp-Session-Id header:
curl -i -X POST http://localhost:8080/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "initialize",
    "params": {
      "protocolVersion": "2024-11-05",
      "capabilities": {},
      "clientInfo": {"name": "curl-client", "version": "1.0.0"}
    }
  }'

# 2. List tools over active session:
curl -X POST http://localhost:8080/mcp \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: YOUR_SESSION_ID" \
  -d '{"jsonrpc": "2.0", "id": 2, "method": "tools/list", "params": {}}'

# 3. Call secureVectorSearch tool:
curl -X POST http://localhost:8080/mcp \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: YOUR_SESSION_ID" \
  -d '{
    "jsonrpc": "2.0",
    "id": 3,
    "method": "tools/call",
    "params": {
      "name": "secureVectorSearch",
      "arguments": {
        "query": "Kubernetes cluster security",
        "userPrincipal": "devops@company.com",
        "userRoles": "engineering"
      }
    }
  }'
